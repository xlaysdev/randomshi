# Tweenslop Lab

A mobile-friendly, browser-based tweening playground. Upload an image, choose a motion recipe, tune the chaos, and export a WebM preview.

## Features
- Image upload and drag-and-drop
- Insanity, Mega Bounce, Spin Cycle, Bass Punch, Jelly Wobble and Chaos Trail presets
- Live canvas preview with squash/stretch, rotation, ghost trails, echoes and flashes
- Adjustable speed, intensity, duration and background
- WebM export through the browser's MediaRecorder API

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The site will be available at:

`https://xlaysdev.github.io/randomshi/`

GitHub Pages serves the root `index.html` entry file from the selected publishing source.
